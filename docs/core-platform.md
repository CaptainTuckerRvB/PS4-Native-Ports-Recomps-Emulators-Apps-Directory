# 🔓 Core Homebrew Platform

[← Back to README](../README.md)

These projects form the foundation of the modern PS4 homebrew ecosystem.

---

### [GoldHEN](https://github.com/GoldHEN/GoldHEN)

- Homebrew Enabler
- Plugin Loader
- FTP Server
- Cheat Engine
- FPS Counter
- Remote Package Installation
- Debug Settings

---

### [OpenOrbis PS4 Toolchain](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain)

- Open-source PS4 SDK
- Build homebrew without Sony's SDK

---

### [LibOrbisPkg](https://github.com/OpenOrbis)

- PKG Builder
- PKG Editor
- Package Inspection Tools

---

### [OrbisForge](https://github.com/xeghosted/OrbisForge)

- OpenOrbis Project Wizard
- GoldHEN Plugin Builder
- PKG Generator
