### [ps4debug-NG](https://github.com/Pharaoh2k/ps4debug-NG)
- Latest Version: v1.3.2

Features:
- Process Enumeration
- Memory Reading
- Memory Writing
- Virtual Memory Inspection
- Freeze Support
- Kernel Debugging
- Remote TCP Debugging

Supported Firmware:
- 5.05 through 13.52

Category:
Debugging & Reverse Engineering
