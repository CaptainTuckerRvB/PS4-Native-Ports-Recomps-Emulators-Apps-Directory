### [ps4debug-NG](https://github.com/Pharaoh2k/ps4debug-NG)

The next-generation implementation of ps4debug for jailbroken PlayStation 4 consoles. Compatible with existing ps4debug clients while adding expanded firmware support and additional debugging functionality.

#### Features

- Process Enumeration
- Memory Reading
- Memory Writing
- Memory Freezing
- Virtual Memory Inspection
- Kernel Debugging
- TCP Remote Debugging Protocol
- Wire-Compatible with ps4debug v1.1.19 Clients
